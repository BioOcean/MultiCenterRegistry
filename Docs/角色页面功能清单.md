# 角色页面功能清单

生成时间：2026-06-03

## 对比结论

- 旧系统有效主流程在新系统均有对应入口：门户、登录选角色、病例管理、病例详情、随访、数据统计、质控管理、会议评审、专家评价、账号管理、文献介绍、系统消息、门户介绍。
- 旧系统已废弃或无有效接口的页面不再实现：上报详情、上报详情列表。
- 已按产品决策移除：多语言切换。
- 已按产品决策暂不实现：面板设置。
- 仍需人工验收：门户真实文案、旧表单字段错位数据、`离院方式` 旧值 `5`、服务端 PDF 版式、旧病例意见弹窗细节。

## 本次代码 Review 与清理

- 已清理权限兜底：`FeatureCatalog.CanAccessPath` 对未知页面不再默认放行。
- 已细化页面权限：质控新建仅 `CeateQuality` 可访问；会议新建/编辑仅 `CaseAllocation` 可访问。
- 已补路由常量：`RouteConstants.NotFound`，避免权限规则中散落硬编码路径。
- 未删除文件：当前没有确认可删除的页面文件；`Home` 和 `AdminHome` 是重定向页，仍有用途。
- 未移除 `CaseFormData`：该表已在建表和身份迁移脚本中出现，删除病例时仍用于清理旧数据残留，直接移除风险高。
- 未抽取权限查询服务：`BasePage`、`MainLayout`、导出端点各自需要不同生命周期和上下文，当前重复可接受；强行抽象会增加代码层次。

## 公开访问

| 页面 | 路由 | 功能 |
| --- | --- | --- |
| 门户首页 | `/portal` | 展示项目介绍、协作医院数、评审专家数、登记病例数、疾病类型数、文献介绍、系统消息；进入登录页 |
| 登录页 | `/login` | 账号密码登录、加载可选角色、选择角色、用户协议勾选、公告展示、门户入口 |

## MCR系统管理员

权限：`AccountManager`、`MessageManager`。

默认进入：`/admin/articles`。

| 页面 | 路由 | 功能 |
| --- | --- | --- |
| 文献介绍 | `/admin/articles` | 未发布/已发布文献列表、搜索、分页、新增、编辑、保存草稿、发布、预览、删除 |
| 系统消息 | `/admin/messages` | 系统消息列表、分页、发布消息、删除消息 |
| 门户介绍 | `/admin/portal` | 配置门户/登录页/顶栏标题、介绍、登录公告、用户协议 |
| 账号管理 | `/admin/users` | 用户列表、搜索、分页、创建账号、编辑账号、启用/停用、重置密码、角色分配、医院/科室范围维护 |

## 医院维护

权限：`AccountManager`。

默认进入：`/admin/users`。

| 页面 | 路由 | 功能 |
| --- | --- | --- |
| 账号管理 | `/admin/users` | 用户列表、搜索、分页、创建账号、编辑账号、启用/停用、重置密码、角色分配、医院/科室范围维护 |

## 介入术者

权限：`CaseSubmit`、`CaseEdit`。

默认进入：`/cases`。

| 页面 | 路由 | 功能 |
| --- | --- | --- |
| 病例管理 | `/cases` | 病例列表、状态页签、关键字检索、动态题目多条件检索、医院/经办人/状态筛选、分页、导出、变更经办人、进入详情 |
| 病例详情 | `/cases/{id}` | 查看病例摘要、表单导航、附件查看下载、审核意见、编辑并保存病例表单、提交审核 |
| 随访消息 | `/followups` | 查看 30 天/一年未填随访病例、汇总提醒、进入病例详情补填 |
| 数据统计 | `/statistics` | 查看本人范围内病例、质控、会议、评审状态统计、月度趋势、专项统计和题目答案分布 |

## 医院质控员

权限：`CaseApprove`、`CaseEdit`、`CeateQuality`、`CreateCase`、`DeleteCase`。

默认进入：`/cases`。

| 页面 | 路由 | 功能 |
| --- | --- | --- |
| 病例管理 | `/cases` | 病例列表、状态页签、动态题目检索、医院/经办人/状态筛选、创建病例、编辑病例、删除病例、变更经办人、导出、进入详情 |
| 新建病例 | `/cases/new` | 创建病例并按疾病模板初始化表单 |
| 病例详情 | `/cases/{id}` | 查看病例、保存表单、审核通过、审核不通过、查看/维护审核意见、删除病例 |
| 质控管理 | `/quality` | 质控列表、医院/疾病/月度/状态筛选、月度上报统计、未上报医院明细、进入详情、新建质控 |
| 新建质控 | `/quality/new` | 按质控模板和月份创建质控报表并初始化表单 |
| 质控详情 | `/quality/{id}` | 查看表单、保存表单、提交质控、查看驳回记录、页面内 PDF 预览、服务端 PDF 下载 |
| 数据统计 | `/statistics` | 按角色医院/科室范围查看病例、质控、会议、评审状态统计、月度趋势和专项统计 |

## 质控中心管理员

权限：`CaseAllocation`、`CreateCase`、`DeleteCase`、`ViewEvalueation`、`ViewQuality`。

默认进入：`/statistics`。

| 页面 | 路由 | 功能 |
| --- | --- | --- |
| 数据统计 | `/statistics` | 全局病例、质控、会议、评审状态统计、月度趋势、医院病例数、专项统计、题目答案分布、专项导出 |
| 病例管理 | `/cases` | 全局病例列表、动态题目检索、创建病例、导入模板、导入病例、导出、删除病例、进入详情 |
| 新建病例 | `/cases/new` | 创建病例并初始化表单 |
| 病例详情 | `/cases/{id}` | 查看病例、附件、审核意见；对已上报病例执行质控退回；删除病例 |
| 质控管理 | `/quality` | 质控列表、筛选、月度上报统计、未上报医院明细、质控导出、进入详情 |
| 质控详情 | `/quality/{id}` | 查看表单、驳回质控、删除质控、服务端 PDF 下载 |
| 评审会议 | `/meetings` | 会议列表、搜索、状态筛选、新建会议、会议导出、进入详情 |
| 新建/编辑会议 | `/meetings/new`、`/meetings/{id}/edit` | 维护会议标题、时间、地点、分组、状态、专家和组长 |
| 会议详情 | `/meetings/{id}` | 查看会议、专家、病例；添加病例、移除病例、病例排序、开始/发布/结束会议、删除会议 |
| 专家评价 | `/meetings/{meetingId}/cases/{caseId}/appraise` | 查看病例对照、所有专家评审、汇总、题目统计、历史投票记录、服务端 PDF 下载 |

## 质控专家

权限：`CaseEvalueation`、`ViewEvalueation`。

默认进入：`/meetings`。

| 页面 | 路由 | 功能 |
| --- | --- | --- |
| 评审会议 | `/meetings` | 查看本人相关会议、搜索、状态筛选、进入会议详情 |
| 会议详情 | `/meetings/{id}` | 查看会议信息、专家列表、会议病例、进入病例或专家评价 |
| 病例详情 | `/cases/{id}` | 只读查看病例表单、附件和审核意见 |
| 专家评价 | `/meetings/{meetingId}/cases/{caseId}/appraise` | 病例对照、附件查看下载、本人评审表单保存/提交、查看其他专家评价、组长汇总保存/提交、题目答案统计、历史投票记录、服务端 PDF 下载 |

## 超级管理员

权限：全部 MCR 权限。

默认进入：`/cases`。

| 页面 | 路由 | 功能 |
| --- | --- | --- |
| 临床业务全部页面 | `/statistics`、`/cases`、`/quality`、`/meetings` 等 | 拥有病例、质控、会议、评审、导入导出和专项统计全部操作 |
| 后台维护全部页面 | `/admin/users`、`/admin/articles`、`/admin/messages`、`/admin/portal` | 拥有账号管理、文献介绍、系统消息、门户介绍全部操作 |

说明：超级管理员因为同时拥有多组权限，默认按旧登录优先级进入病例管理；进入后台维护可使用后台角色或直接访问后台路由。
